# Mahila Shakti Vikas Foundation Website

Ready-to-run static website created from the supplied website structure.

## Languages
All pages open in Hindi by default. Use the Hindi/English button in the navigation menu to switch languages; the preference is remembered as you move between pages.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. For best local development, run a simple server:
   - Python: `python -m http.server 8000`
   - Then open: `http://localhost:8000`

## Before going live
Replace:
- phone number
- email
- verified office address
- bank account and IFSC
- UPI ID and QR image
- sample impact numbers on the Our Work page
- gallery placeholder blocks
- social media URLs

## Important
The forms currently demonstrate client-side validation only. Connect them to your backend/API/email service before production.
